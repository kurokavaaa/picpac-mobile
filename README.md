# PicPac — мобильное приложение для печати фото и фотокниг

Прототип для хакатона **SpaceHackathon × Фотопринт (PicPac), Трек 2 — мобильное приложение**.
Команда № 9, лидер — Лапатин.

Идея: от фотографии в смартфоне — к заказу фотопродукции в несколько нажатий, без переноса фото на компьютер
и без неудобной мобильной версии сайта.

> Это прототип. Оплата тестовая, уведомления и ИИ — имитация. Цены и характеристики взяты с
> [super.picpac.by](https://super.picpac.by) (ноябрь 2026); то, чего на сайте нет, помечено в приложении
> как «ориентировочно».

## Что умеет приложение

- **Каталог:** фотопечать, фото на документы, коллаж, фотоальбом, фотокниги Lite / Classic / Premium
  с ценами и характеристиками с сайта.
- **Фотопечать:** размеры в см, вид печати (фотохимическая / цифровая), поверхность (глянцевая / матовая).
- **Фото на документы:** паспорт РБ 40×50 мм, паспорт РФ и шенгенская виза 35×45 мм, виза США 50×50 мм,
  медкнижка 30×40 мм — раскладка копий на листе 10×15 и подсказка для кадрирования.
- **Фотоальбом:** «собрать самому» или один из готовых макетов на фиксированное число страниц.
- **Конструктор страниц:** около 60 раскладок на 1–7 фото, перетаскивание фото между ячейками
  (удержать и потянуть), свободный режим, тексты, стикеры, 15 дизайнов, предпросмотр с перелистыванием.
- **Регистрация** по email или телефону с капчей; уведомления — на email или SMS.
- **Корзина и заказ:** промокод, бонусы и уровни клиента, доставка, тестовая оплата (в том числе отказ банка),
  лента статусов заказа. Повторное нажатие «Оформить» не создаёт дубликат.
- **Чат поддержки:** помощник отвечает на частые вопросы, по кнопке подключается менеджер (имитация).
- **Обучение при первом входе:** экран затемняется, подсвечивается нужная кнопка, есть «Пропустить».
- Светлая и тёмная тема, фирменные иллюстрации с котом.

## Технологии

| Часть | Что используем |
|---|---|
| Приложение (`android/`) | Kotlin 2.4.21, Jetpack Compose (BOM 2026.09.00), Material 3, Android Gradle Plugin 9.5.1, Gradle 9.8.2, minSdk 26, targetSdk 37 |
| Хранение данных | JSON-файл на телефоне (`org.json`, атомарная запись) — приложение работает без сервера |
| Фото | Системный выбор фото: приложение видит только отмеченные пользователем снимки |
| Шрифты | Jost (аналог Futura PT из брендбука) и шрифты для подписей — все OFL, с кириллицей |
| Сервер (`backend/`) | Ktor 3.6.1, Kotlin, Java 21, SQLite, JWT, капча, пакет для печати (ZIP + штрихкоды листов), автотесты |

Сервер написан, но к приложению пока не подключён: в демо всё работает на телефоне.

## Как запустить приложение

1. Установите [Android Studio](https://developer.android.com/studio).
2. `File → Open` → папка **`android`** (не корень репозитория).
3. Дождитесь синхронизации Gradle (нужен интернет при первом открытии).
4. Выберите эмулятор или телефон с включённой «Отладкой по USB» и нажмите ▶ Run.

Сборка из терминала: `cd android && ./gradlew :app:assembleDebug` (нужна Java 17+, подойдёт JDK из Android Studio).

Подробнее и сценарий для проверяющего — в [android/README.md](android/README.md).
Запуск сервера — в [backend/README.md](backend/README.md).

## Планы

1. Подключить приложение к серверу: аккаунты, заказы и оплата — на сервере.
2. Настоящая оплата (VISA, Mastercard, БЕЛКАРТ, ЕРИП); производство — только после оплаты.
3. Настоящий ИИ вместо имитации: подбор макета, правка фото, помощник в чате. Ключи — только на сервере.
4. Модерация загружаемых фото.
5. Уведомления о статусе заказа по email и SMS.
6. Безопасное хранение паролей на сервере (сейчас в демо — простой хеш на телефоне).
7. Версия для iOS.
